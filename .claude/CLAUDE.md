This is an ongoing software project to run a system on a Raspberry Pi for a church belfry for bell ringers to see information and hear bell sounds from sensor connected to the bells.

Current status - early development: nothing is released, breaking changes are no problem.

Docs:

* README.md - public facing readme doc for users: only include content for future users setting up and using their system
* docs/development.md - notes on running on a Mac and debugging
* docs/requirements.md - high level assertions on what the system should do: don't edit these
* docs/tower-system-design.md - a breakdown of the requirements into a design and implementation plan
